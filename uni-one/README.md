# Подружимся? — прототип

**Приложение для знакомств и социализации студентов.** Интерактивный прототип
в тёмной теме по дизайн-макетам (МГУ): свайп-знакомства, мэтчи, мероприятия и
чаты.

## Экраны

1. **🏠 Главная** — свайп-знакомства (drag влево/вправо + кнопки ✕ / ★ / ❤),
   карточка с фото, факультетом, интересами и расстоянием. Взаимный лайк →
   экран «Это мэтч!».
2. **🎉 Мероприятия** — лента событий с обложками и бейджами «ГОРЯЧО»/«НОВОЕ»,
   фильтры (Все / Сегодня / МГУ / Онлайн), запись в один клик.
3. **❤️ Пары** — сетка совпадений, кнопка «Написать».
4. **💬 Сообщения** — лента «Новые мэтчи», список чатов с непрочитанными,
   «Поиск знакомых», открытие диалога с рабочим вводом сообщений.
5. **👤 Профиль** — аватар с градиентной рамкой, статистика (Лайки / Мэтчи /
   Друзья), «О себе», интересы.

Данные — мок (`src/data.js`), фото подгружаются с pravatar.cc / picsum.photos
(при отсутствии сети показывается градиентная заглушка). Прогресс хранится в
`localStorage`, бэкенд не нужен.

## Стек

- React 19 + Vite, тёмная дизайн-система на чистом CSS
- Иконки — инлайн-SVG (`src/components/Icon.jsx`)

## Запуск

```bash
cd uni-one
npm install
npm run dev      # http://localhost:5173
```

### Один файл для телефона

`npm run build:single` собирает всё в единый самодостаточный
`dist-single/index.html` — открывается на телефоне/компе без сервера.

## Структура

```
src/
  data.js                 # мок-данные: анкеты, события, чаты, профиль
  App.jsx                 # навигация, состояние, экран мэтча, роутинг чата
  index.css               # тёмная дизайн-система
  components/
    Icon.jsx              # набор SVG-иконок
    SmartImg.jsx          # картинка с заглушкой при офлайне
    Discover.jsx          # свайп-знакомства
    Events.jsx            # мероприятия
    Matches.jsx           # пары
    Messages.jsx          # сообщения + поиск знакомых
    ChatThread.jsx        # экран диалога
    Profile.jsx           # профиль
```

> Прототип для демонстрации концепции — логика работает на клиенте, чтобы
> показывать продукт без развёртывания сервера.
