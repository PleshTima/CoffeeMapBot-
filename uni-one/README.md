# Uni-one — прототип

**Приложение для ускорения социализации студентов.** Интерактивный прототип
веб-приложения по концепции из презентации команды (ДМ_команда 1).

> Единая цифровая экосистема, где первокурсник сразу видит всю внеучебную жизнь
> университета, находит «своих» по интересам и записывается на события в один
> клик — ещё до первой встречи в аудитории.

## Что внутри (3 модуля из презентации)

1. **📅 Афиша** — единый календарь всех событий и кружков с фильтрами по теме
   и фильтром «для новичков». Запись в один клик, индикатор свободных мест.
2. **🤝 Сообщества по интересам** — тематические группы и чаты, поиск «своих»
   по хобби. Сообщества под твои интересы подсвечиваются меткой «твоя тема».
3. **🏆 Профиль / геймификация** — онбординг первокурсника («Ты только
   поступил?»), XP и уровни, ачивки за активность, идентика «свой-чужой».

Данные — мок реальных клубов и событий из презентации (Вечерняя гитара,
7 o'clock tea, «Эконом говорит», Шахматный клуб, «Что? Где? Когда?» и др.).
Прогресс сохраняется в `localStorage` (бэкенд не требуется). Сбросить демо —
тап по чипу `⚡ XP` в шапке.

## Стек

- React 19 + Vite
- Без бэкенда: мок-данные в `src/data.js`, состояние в `localStorage`

## Запуск

```bash
cd uni-one
npm install
npm run dev      # http://localhost:5173
```

Сборка прод-версии:

```bash
npm run build && npm run preview
```

## Структура

```
src/
  data.js                 # мок-данные: события, сообщества, интересы, профиль
  App.jsx                 # навигация, состояние, логика XP/ачивок
  index.css               # дизайн-система в палитре презентации
  components/
    Onboarding.jsx        # сценарий первокурсника + выбор интересов
    Afisha.jsx            # календарь событий с фильтрами и записью
    Communities.jsx       # сообщества по интересам, поиск «своих»
    Profile.jsx           # геймификация: XP, уровни, ачивки
```

> Прототип для демонстрации концепции. Логика намеренно работает на клиенте,
> чтобы можно было показать продукт без развёртывания сервера.
